# kxrim.dev

Personal portfolio of Kerimcan Yagci — software developer, Austria.

React Three Fiber scene with a scroll-driven camera, custom GLSL displacement material,
GSAP + Lenis choreography. Typeset in Archivo and IBM Plex Mono. No template.

```sh
npm install
npm run dev      # develop
npm run build    # static build → dist/
```

See `CLAUDE.md` for architecture and conventions, `ASSETS.md` for asset licensing.
